# @deepseek-ai/dsh-api-jev-router

[English](README.md) | 中文

## 概述

`jevRouter` Remote 请求 Jev 决策模型评估提示的复杂度，并把 Session 的下一个模型步骤切换到对应的已配置层级。浏览器在自动模型模式下提交提示前调用 `route`；服务端不设模式开关。

<a id="use-this-package"></a>
## 使用此包

在 `cordis.yml` 中按从易到难的顺序配置 `tiers`，索引即层级。路由至少需要两个层级，以及 `apiKeyEnv` 指定的凭据（默认 `OPENROUTER_API_KEY`，每次调用经凭据服务或启动环境解析）。缺少任一项时，`route` 返回 `{ routed: false, reason: 'disabled' }`，插件保持惰性。

`route({ sessionId, text })` 向 Jev 请求一次针对每个层级的评分。概率最高的层级胜出；当 Jev 的置信度低于 `minConfidence`（默认 `0.6`）时，路由向上升一个层级，并以最难层级为上限。`routed: true` 的结果携带层级与所选路由。`unchanged` 表示 Session 已使用该路由。`jev-unavailable` 表示 Jev 失败、超时或返回了意外结构；当前模型保持不变。未知或无权访问的 Session 以 Session 错误拒绝。

`endpoint` 与 `model` 默认指向 OpenRouter Decisions API 与 `typesafe/jev-1.14`。`timeoutMs`（默认 `3000`）限制 Jev 调用时长。`maxChars`（默认 `8000`）保留长提示的末尾字符。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>维护者信息 — 点击展开</summary>

Remote 通过 `sessionController.resolveAgent` 解析 Session 的 Agent，与 Session Remote 走同一路径。它用 `llm.resolveCallConfig` 校验所选路由，再以 `agent.model.select` 记录，后者追加一个 `model/selection` 事件。它不调用 `session.selectModel`，那会同时为新 Session 持久化默认值。

`src/jev-client.ts` 构造一个名为 `complexity` 的 `score` 问题，每个层级一条标准，并读取 `answers.complexity` 的 `probabilities` 与 `confidence`。该线上格式尚未用真实密钥验证，见该文件中的 `shortcut:` 注释。`src/policy.ts` 包含纯函数的层级选择与提示截断。

Jev 调用的每种失败——网络错误、超时、非 2xx 状态或无法解析的响应——都返回 `jev-unavailable`。调用方取消仍会以拒绝结束。

<a id="model-experience"></a>
## 模型体验

### 请求上下文与条件

#### 模型所见内容

发生切换时，下一个模型步骤在所选路由上运行，Agent 在该步骤前追加一条用户消息。该消息即既有的模型切换提示，由 Agent 生成，不由本包生成；`{from}` 与 `{to}` 为先前路由与所选路由，两者提供方相同时省略提供方。

##### 模型切换提示文本

```markdown
[model changed: assistant turns above this point were generated by {from}; the session continues with {to}]
```

#### Token 影响

每次切换增加一条简短的用户消息以及路由标签。Jev 调用消耗 Jev 模型的 token，不进入 Session 的模型请求。

#### KV 缓存影响

切换会改变模型请求头，因此下一步无法复用先前路由的缓存前缀；提示追加在该历史之后。选择当前路由，或路由被禁用或不可用时，Session 的请求保持不变。Jev 调用是独立请求，不改变 Session 的缓存。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **子代理、计划任务与 ACP 提示绕过路由** — 只有浏览器调用 `route`；被委派的子代理、计划后续任务以及仅供自动化的 ACP 提交使用 Session 当前模型。
- **图像提示未经检查** — `route` 只接收文本。切换到不能读图的层级后，图像提示可能被送入该模型。
- **提示文本离开部署环境** — `text` 发送至已配置的 Jev 端点（使用默认 OpenRouter 端点时为第三方），并截断至 `maxChars`，保留末尾。
- **层级标准来自 `description`** — Jev 按每个层级的 `description` 评分；未填写的层级以 `Tier <index>` 发送，只体现其顺序。
